🚗 Monthly Car Sales Analysis & Forecasting
📌 Overview

The Monthly Car Sales Analysis project leverages data analytics, machine learning, and time series forecasting to analyze historical automobile sales data and predict future sales trends.
It provides actionable insights into brand performance, model demand, regional trends, and seasonal patterns, helping stakeholders make informed decisions in marketing, inventory planning, and business strategy.

🎯 Objectives

Analyze monthly car sales trends across multiple dimensions

Identify seasonal patterns and consumer preferences

Forecast future car sales using time series models

Support data-driven decision-making in the automobile industry

📊 Key Features

Exploratory Data Analysis (EDA)

Sales trends by brand, model, and region

Seasonal and monthly demand patterns

Growth and decline analysis

Time Series Forecasting

Monthly sales prediction using statistical and ML models

Trend and seasonality decomposition

Model performance evaluation

Business Insights

High-performing and underperforming brands/models

Regional demand comparison

Inventory and marketing strategy recommendations

🧠 Technologies Used

Programming Language: Python

Libraries & Tools:

Pandas, NumPy – Data processing

Matplotlib, Seaborn – Data visualization

Scikit-learn – Machine learning

Statsmodels / Prophet – Time series forecasting
